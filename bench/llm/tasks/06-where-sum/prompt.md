# Task 06-where-sum

Write a complete program in {{LANG}}.

## Goal

Start from the integer list `4, 7, 2, 9, 12`.

1. Keep only values strictly greater than `5`
2. Sum the kept values
3. Print a single line: `Sum: ` followed by that total (no quotes)
4. Assert / panic if the total is not `28`

## Expected stdout

```text
Sum: 28
```

## Constraints

- Single source file
- No network, no files, no command-line args, no stdin
- Exit successfully after printing (assertion must pass)
