# Task 10-fibonacci

Write a complete program in {{LANG}}.

## Goal

Generate the first eight Fibonacci numbers iteratively, starting with `0, 1`.
Print each number on its own line. Update program state on each iteration rather
than storing or printing a precomputed answer.

## Expected stdout

```text
0
1
1
2
3
5
8
13
```

## Constraints

- Use a loop and mutable state
- Do not hard-code the eight output lines or a completed Fibonacci collection
- Single source file; no network, files, arguments, or stdin
