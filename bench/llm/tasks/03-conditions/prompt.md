# Task 03-conditions

Write a complete program in {{LANG}}.

## Goal

Set `temperature` to `24` and `sunny` to `true`.

If temperature is at least 20 **and** sunny is true, print:

`Good weather for a walk.`

Otherwise print:

`Stay inside and write VOL.`

With the given values, the first message must be printed.

## Expected stdout

```text
Good weather for a walk.
```

## Constraints

- Single source file
- Use a real conditional (if / else), not only a hard-coded print of the success string without checking the values
- No network, no files, no command-line args, no stdin
- Exit successfully after printing
