# Task 05-arrays-each

Write a complete program in {{LANG}}.

## Goal

Create the integer collection `72, 95, 81, 64`. Print its original item count,
change the fourth score from `64` to `70`, then iterate over the collection and
print only scores greater than or equal to `80`, preserving their order.

## Expected stdout

```text
Students: 4
High score: 95
High score: 81
```

## Constraints

- Use collection indexing for the mutation and iteration for the filtering
- Compute the count and selected scores; do not hard-code the completed output
- Single source file; no network, files, arguments, or stdin
