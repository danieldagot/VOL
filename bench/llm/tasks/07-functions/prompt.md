# Task 07-functions

Write a complete program in {{LANG}}.

## Goal

Define two functions:

1. `greet(name)` — returns the string `Hello, ` concatenated with `name`
2. `square(number)` — returns `number * number`

Then:

- Print `greet("friend")`
- Print `Six squared is ` concatenated with the decimal form of `square(6)`

## Expected stdout

```text
Hello, friend
Six squared is 36
```

## Constraints

- Single source file
- Must call the two functions (do not only hard-code both final strings)
- No network, no files, no command-line args, no stdin
- Exit successfully after printing
