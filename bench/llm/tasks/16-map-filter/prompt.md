# Task 16-map-filter

Write a complete program in {{LANG}}.

## Goal

Start from the integer list `1, 2, 3, 4, 5, 6, 7, 8`.

1. Multiply every element by `3`
2. Print the count of mapped values that are `> 10` and `< 20`
3. Print the sum of mapped values that are `> 10`

Two lines, bare integers, no labels. Prefer map / filter / count / sum when
the language supports them.

## Expected stdout

```text
3
90
```

## Constraints

- Compute from the list; do not hard-code both results as literals alone
- Single source file; no network, files, arguments, or stdin
