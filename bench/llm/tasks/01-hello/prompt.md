# Task 01-hello

Write a complete program in {{LANG}}.

## Goal

Print a two-line greeting that names the language `VOL` and prototype version `1`.

You may use variables, but the printed text must match exactly.

## Expected stdout

```text
Hello from VOL
Prototype version 1
```

## Constraints

- Single source file
- No network, no files, no command-line args, no stdin
- Exit successfully after printing
