# Task 02-arithmetic

Write a complete program in {{LANG}}.

## Goal

Use integers `a = 10` and `b = 3`. Compute:

1. sum (`a + b`)
2. product (`a * b`)
3. difference (`a - b`)

Print each result on its own line, in that order.

## Expected stdout

```text
13
30
7
```

## Constraints

- Single source file
- No network, no files, no command-line args, no stdin
- Exit successfully after printing
